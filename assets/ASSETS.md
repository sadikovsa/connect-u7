# Изображения, ролики и шрифты: происхождение

Сверено со страницей `index.html` (ссылки из HTML, CSS и JS) 2026-10-11. Все материалы seventech.uz взяты с https://seventech.uz/market/product-page/smartfon-connect-u7-8256-gb-black-7tcmpu76g8256bs1 с разрешения пользователя (2026-10-08). Права на фото, ролики и логотип 7TECH подтверждены только словами пользователя, письменного согласия владельца нет.

Исходные файлы лежат в `.studio/source-images/` и `.studio/source-media/` (в поставку не входят). Сборка WebP: `node tools/make-images.js` и остальные скрипты в `tools/`. У каждого файла в `assets/img/` и постера в `assets/video/` рядом лежит `.json` с происхождением (стандарт студии, проверка `embed-prompt --scan assets`). Колонка «Нейросеть»: да = создано или перерисовано `gpt-image-2.5-flare` (ключ пользователя); нет = не нейросеть.
