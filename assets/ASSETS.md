# Изображения и шрифты: происхождение

Все файлы взяты с https://seventech.uz/market/product-page/smartfon-connect-u7-8256-gb-black-7tcmpu76g8256bs1 с разрешения пользователя (2026-10-08), кроме отмеченных «нейросеть». Права на фото и логотип 7TECH подтверждены только словами пользователя, письменного согласия владельца нет.

Исходные файлы лежат в `.studio/source-images/` (в поставку не входят). Сборка WebP: `node tools/make-images.js`. У каждого файла в `assets/img/` рядом лежит `.json` с описанием происхождения (стандарт студии), у PNG-плиты оно внутри файла.
